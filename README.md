# Hub Universe
App #7 of the Hub family by Marvel Corp - every Hub app on your phone in one place.
Live at https://smarvel1963-ops.github.io/hubuniverse/ . The page, icons and offline worker live here; the app code is the
shared Hub engine in the dayhub repo (`DH_MODE = "universe"`, `universe.js`). It reads the other hubs' data on the phone,
read-only. No ads, ever.
